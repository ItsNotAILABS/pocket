## 2. Marks to **not** file / do not use as our marks

| Term | Why |
|---|---|
| **PHONE.AI** / **PHONE AI** (two words) | Ad Hoc Labs, Inc. — U.S. serial **99230184** (filed 11 Jun 2025), classes 9/38/42, voicemail and AI receptionist. High likelihood-of-confusion risk if we brand “Phone AI” for a phone product. Use **PhoneAI Kernel** / **PhoneAI OS** and a different logo. |
| **POCKET** (alone) | Extremely crowded (Mozilla Pocket / Read It Later, apparel, wallets). Weak; use **POCKET HOST** / **POCKET OS** + logo. Common-law use as product name on GitHub still fine; federal registration of POCKET solo is a fight. |
| **PORTAL** (alone) | Generic for a gateway. Use **POCKET PORTAL** as a product feature name, not a registration target. |
| **FACE ID** | Apple trademark. Say “passkey / WebAuthn / device pair,” not Face ID in marketing as a mark. |
| **ANTIGRAVITY** | Google product. We stream *their* app; we do not brand ours Antigravity. |
| **WEBMCP** | Chrome / Google proposed web standard. We may *implement* page tools; we must not trademark WebMCP. |
| **MCP** | Anthropic/open protocol. Descriptive. |
| **MAGICDESK**, **CITRIX**, **WINDOWS 365** | Third-party. |

## 3. How to brand in product copy (from this research)

- **PhoneAI** always as one word, preferably followed by **Kernel** or **OS**.
- First mention: “PhoneAI Kernel (not a phone receptionist).”
- **POCKET** as the host product; “POCKET host” in sentences.
- **vLaptop** with a capital L in marketing; **VLAPTOP** in filings.
- **SCREEN-KERNEL/1.0** as the protocol name on `/v1/screen/kernel` and in vLaptop.
- Footer: `PhoneAI Kernel™` and `POCKET™` with ™ until registered; ® only after registration.
